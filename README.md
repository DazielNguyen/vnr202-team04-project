# VNR202 — Bước ngoặt 1930

Interactive historical storytelling product trả lời câu hỏi: “Những điều kiện lịch sử và chính trị nào khiến sự ra đời của Đảng Cộng sản Việt Nam năm 1930 trở thành bước ngoặt?”

## Chạy dự án

```bash
npm install
npm run dev
```

Build production: `npm run build`.
